# Rough Heston Option Pricing and SPX Calibration

## Overview

This repository contains the numerical work developed as part of a
final-year project on option pricing and calibration under fractional
volatility models, with a particular focus on the **Rough Heston model**
and its application to **SPX options**.

The project follows a progressive approach from classical option-pricing
models to rough volatility. It covers fractional Brownian motion, the
numerical solution of the fractional Riccati--Volterra equation,
Fourier-based option pricing, and the calibration of Rough Heston to
real SPX option data.

A central objective is to compare **Rough Heston** with the classical
**Heston model**, especially through implied-volatility surfaces,
smiles, calibration errors, and the short-maturity ATM skew.

The work was carried out by **Gaspar Raybaud-Mabily and Aladin Alloui**
as a final-year project in Mathematical Modelling for Finance at CY
Tech, academic year 2025--2026.

### 01 --- Black--Scholes

Introduces implied volatility and illustrates the smile, skew and
implied-volatility surface that motivate more flexible volatility
models.

### 02 --- Heston

Implements the classical Heston stochastic-volatility model and studies
the implied-volatility smiles and surface generated by stochastic
variance.

### 03 --- Fractional Brownian motion

Introduces the numerical tools used to study rough volatility:

-   Cholesky simulation of fractional Brownian motion;
-   Davies--Harte simulation;
-   numerical estimation of the Hurst parameter.

### 04 --- Rough Heston theory

This chapter of the project is theoretical and therefore contains no
standalone numerical implementation. It develops the Rough Heston model,
its Volterra formulation, the role of the fractional kernel and the
connection with classical Heston.

The numerical implementation of these ideas begins in the following
chapters.

### 05 --- Fractional Riccati equation

Implements the fractional Riccati--Volterra equation arising in the
Rough Heston characteristic function.

The numerical analysis includes:

-   fractional Adams predictor--corrector scheme;
-   validation through the Heston limit;
-   comparison with a fractional Euler scheme;
-   numerical convergence analysis.

### 06 --- Fourier option pricing

Builds the option-pricing framework from the Rough Heston characteristic
function.

The chapter includes:

-   Gil--Pelaez inversion;
-   COS pricing;
-   numerical stability comparisons;
-   implied-volatility extraction;
-   ATM-skew computation;
-   parameter-sensitivity analysis;
-   comparison between Rough Heston and classical Heston.

### 07 --- SPX calibration

Applies the pricing framework to real SPX option data.

The calibration pipeline is divided into six stages:

1.  **Data preparation** --- inspection and filtering of SPX/SPXW
    quotes, construction of the GSW zero-coupon curve, estimation of
    spot and dividend yield, and construction of the calibration sample.
2.  **Optimization methods** --- comparison of multi-start TRF with
    Differential Evolution followed by TRF, together with numerical
    robustness tests.
3.  **Global calibration** --- calibration of Rough Heston and classical
    Heston over the full selected maturity range.
4.  **Global analysis** --- comparison of model surfaces, smiles,
    calibration errors, ATM skew and its maturity dependence.
5.  **Short-term calibration** --- dedicated calibration over maturities
    up to 31 days.
6.  **Short-term analysis** --- detailed study of short-maturity smiles,
    errors and ATM-skew behaviour.

## Calibration methodology

The empirical calibration minimizes discrepancies between **market and
model implied volatilities**.

Two numerical strategies are investigated for Rough Heston:

-   multi-start **Trust Region Reflective (TRF)** optimization;
-   **Differential Evolution (DE)** followed by TRF refinement.

Additional robustness tests study the sensitivity of the numerical
results to the discretization and COS-pricing parameters.

Classical Heston is calibrated on the same option sample to provide a
consistent benchmark.

## Data

The empirical study uses SPX and SPXW option quotes together with U.S.
Treasury zero-coupon information used to construct the
maturity-dependent interest-rate curve.

The data-processing scripts document the complete transformation from
raw quotes to the final calibration sample, including:

-   maturity construction;
-   bid--ask and liquidity filters;
-   no-arbitrage checks;
-   forward-price construction;
-   OTM option selection;
-   implied-volatility inversion;
-   maturity and moneyness selection.

## Installation

Clone or download the repository and place the complete
`rough-heston-option-pricing` folder inside the directory used as your
Python working directory.

The project paths are built from the current Python working directory:

```python
ROOT_DIR = Path.cwd() / "rough-heston-option-pricing"
```

The expected structure is therefore:

```text
<python-working-directory>/
└── rough-heston-option-pricing/
    ├── 01_black_scholes/
    ├── 02_heston/
    ├── ...
    ├── 07_spx_calibration/
    ├── requirements.txt
    └── rough_heston_project_report.pdf
```

Then install the required Python packages:

```bash
pip install -r rough-heston-option-pricing/requirements.txt
```

The project requires:

- NumPy
- pandas
- SciPy
- Matplotlib

------------------------------------------------------------------------

## Running the code

Scripts are organized in the same order as the project methodology. For
the empirical SPX section, they should be run sequentially because later
stages use CSV files generated by earlier stages.

Before running the scripts, make sure that the Python working directory
is the parent directory of `rough-heston-option-pricing`, as described
in the installation section above.
