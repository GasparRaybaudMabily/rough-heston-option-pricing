# Rough Heston Theory

This chapter presents the theoretical foundations of the 
**Rough Heston model** developed in the project.

It introduces the Volterra formulation of the variance process, the fractional 
kernel and the role of the Hurst parameter in modelling rough volatility. 
It also establishes the connection between Rough Heston and the classical
Heston framework.

No standalone numerical code is associated with this chapter. 
The numerical implementation of the model begins in the following chapters,
with the fractional Riccati–Volterra equation and Fourier-based option pricing.

For the complete mathematical development, see the full project report 
in the root directory.
